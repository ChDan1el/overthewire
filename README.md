# OverTheWire Write-ups

Este repositório reúne write-ups dos desafios do site [OverTheWire](https://overthewire.org/), com foco em explicar o raciocínio utilizado para resolver cada nível.

## Sobre

O OverTheWire é uma plataforma de wargames voltada para o aprendizado de segurança da informação. Os desafios abordam temas como Linux, redes, segurança web, criptografia, exploração e análise de código.

## Wargames

Os write-ups estão organizados por wargame:

```text
.
├── README.md
├── natas/
├── bandit/
├── leviathan/
└── ...
```

## Objetivo

O objetivo deste repositório é registrar soluções, comandos, técnicas e aprendizados obtidos durante a resolução dos desafios.

## Aviso

Este repositório contém spoilers das soluções. Recomendo tentar resolver os desafios por conta própria antes de consultar os write-ups.

## Finalidade

Todo o conteúdo aqui é voltado exclusivamente para fins educacionais e prática em segurança da informação.
